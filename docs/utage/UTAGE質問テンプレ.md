## 🟢 最初に1回だけ送る「コンテキスト共有メッセージ」

UTAGE chat の新しいスレッドの最初に貼って、私のケースの全体像を伝える。
スタンスは「**私はこういうことをしたい→UTAGE標準/公式マニュアル基準で正解を教えて**」。
具体的な手順は押し付けず、UTAGE側に推奨を出してもらう。

```
これからUTAGEでファネル構築を行うので、まず私のケースの全体像を共有させてください。
今後、各機能ごとに「これを実装したいです、UTAGE標準ではどういう手順ですか」と
個別質問していきますので、その都度、公式マニュアルに沿った推奨手順・関連マニュアルURL・
注意点を教えていただけると助かります。

────────────────────────────────────────
■ プロジェクト概要
────────────────────────────────────────

クライアント案件で、3つのサービスのファネル・LINE配信・決済・会員サイトを
UTAGEで構築します。LPは既に外部サイト（Vercel）で完成しているので、
UTAGE側はLP以降のファネル機能を担当します。

【サービス構成】
- BizOwner：月額50,000円サブスク（ビジネス初心者向け副業）
- SARUDEMO：一括300万円（CICホワイト向け本格起業）
- ビジネスの学び家：月額10,000円サブスク（コミュニティ）

────────────────────────────────────────
■ LINE構成
────────────────────────────────────────

LINE公式アカウントを2つ運用したいです：

・LINE① 共通公式
   → BizOwner LP・学び家 LP からの流入CV先
   → 自動シナリオ中心の運用

・LINE② SARUDEMO専用
   → SARUDEMO LPからの流入CV先
   → 高単価商材のため個別対応比率を上げる運用

このように複数のLINE公式アカウントを1つのUTAGE環境で運用する場合の
推奨構成・注意点・関連マニュアルがあれば教えてください。

────────────────────────────────────────
■ 実現したいファネル全体像
────────────────────────────────────────

[3LP] → [LINE①or②] → [簡易アンケート3-4問] → [短尺ステップ配信＋動画]
  → [ウェビナー or 個別面談] → [決済フォーム] → [メンバーサイト＋紹介URL]

────────────────────────────────────────
■ 実装したい主な機能
────────────────────────────────────────

【決済フォーム（5種類）】
1. BizOwner月額50,000円（初月無料・学び家オプションをチェックで追加可）
2. SARUDEMO一括300万円（クレカ可・学び家オプ追加可）
3. 学び家単独 月10,000円（学び家LPと会員サイト両方から呼び出したい）
4. 法人作成スポット10万円（会員サイトのボタンから呼び出し）
5. FC加盟スポット500万円（個別面談後にURL送付・一般非公開）

【ラベル/タグ】
以下4カテゴリのラベルを使い分けたいです：
- 流入元（どのLPから来たかを記録）
- 決済完了（会員サイトの表示制御に使う）
- ウェビナー視聴済み
- 紹介経由フラグ
これらの管理単位・命名・グループ分けについてUTAGE標準の推奨があれば教えてください。

【会員サイト】
- ログイン方式：メアド+パスワード（決済時に自動発行）
- タグ条件で会員ごとに表示エリアを出し分け
  ・BO決済タグ保有者にBO会員コンテンツを表示
  ・SARU決済タグ保有者にSARU会員コンテンツ
  ・学び家決済タグ保有者に学び家コンテンツ
- 「まだ買っていないものを後追い購入できるボタン」を条件表示で出したい
  ・既に買った人にはそのボタンを出さない（鬱陶しさ防止）
- 複数LINE経由の会員が同じ会員サイトに合流する想定ですが、
  これがUTAGE標準で実現可能か・推奨構成を教えてください

【アフィリエイト／紹介プログラム】
- 全会員に紹介URL自動発行
- 紹介経由の登録・決済を自動カウント
- マイページに紹介実績ダッシュボード表示

【その他】
- 個別面談予約（ZOOM自動連携）
- ウェビナー（録画自動配信＋リマインド3段階）
- リッチメニュー（4マス・LINE①②それぞれ）

────────────────────────────────────────
■ イメージしている進め方
────────────────────────────────────────

最初に共通基盤（ファネル・ラベル・LINE連携・会員サイト土台・決済代行連携）を
作ってから、BizOwner+学び家ラインを完走 → SARUDEMOライン展開 → 実コンテンツ搭載
という順序を考えています。

この進め方がUTAGE標準的に妥当か、もっと効率的な進め方があるか、
推奨されるベストプラクティスがあれば教えてください。

────────────────────────────────────────
■ 質問の進め方（お願い）
────────────────────────────────────────

今後、各機能ごとに「この機能を実装したいです、UTAGEではどう進めるのが標準ですか」
と個別質問していきます。

その都度、上記の全体構成を踏まえた上で、
・公式マニュアルに沿った推奨手順
・関連マニュアル/ヘルプ記事のURL
・プラン制限や注意点
を教えていただけると非常に助かります。

私はUTAGEの操作経験がほぼないので、専門用語があれば簡単な説明も
添えていただけると理解が早いです。よろしくお願いします。
```

## Stage 1：共通土台

### Q1-1. ファネル箱を2つ作りたい

```
ファネルを2つ作成したいです。

1つ目：「BizOwner+学び家ファネル」
2つ目：「SARUDEMOファネル」

それぞれ「アンケートフォーム・ステップ配信・決済フォーム・サンクスページ」を中に格納していく予定です。
最もシンプルな空のファネル（テンプレートなし、または最小構成）を作成する手順を教えてください。

また、ファネル単位でフォームやシナリオを後から追加できるか、
プラン上でのファネル作成数の上限があれば併せて教えてください。
```

### Q1-2. タグを12個一括作成したい

```
以下のタグを12個作成したいです。
一括作成（CSV等）が可能か、または1個ずつ作成する手順を教えてください。

【作成するタグ一覧】
- source_BO（BizOwner LPからの流入）
- source_SARU（SARUDEMO LPからの流入）
- source_MANA（学び家 LPからの流入）
- paid_BO（BO月額決済完了）
- paid_SARU（SARUDEMO一括決済完了）
- paid_MANA（学び家決済完了）
- paid_corp_BO（法人作成スポット決済完了）
- paid_FC（FC加盟決済完了）
- webinar_watched_BO（BOウェビナー視聴完了）
- webinar_watched_SARU（SARUDEMOウェビナー視聴完了）
- refer_active（紹介経由の決済発生）
- refer_top（紹介トップランク）

これらは後で「フォーム回答時の自動付与」「決済完了時の自動付与」「会員サイトの表示制御」で
使う予定です。タグにカテゴリやグループ機能があれば、その分類方法も教えてください。
```

### Q1-3. LINE公式アカウントを2つ連携したい

```
LINE公式アカウントを2つUTAGEに連携したいです。

1つ目：BizOwner+学び家 共通用LINE
  → BizOwner LPと学び家LPからのCV先

2つ目：SARUDEMO専用LINE
  → SARUDEMO LPからのCV先
  → 高単価商材のため個別対応比率を上げる運用

それぞれについて、以下を教えてください：
1. LINE Developersでチャネルを作成する手順
2. チャネルアクセストークンを発行する手順
3. UTAGE側でLINEを連携する手順（どのメニューから設定するか）
4. UTAGE発行のWebhook URLをLINE側に設定する手順
5. LINE側の応答モードを「Bot」に切り替える方法
6. 連携できているかテストする方法

なお、UTAGEのプランで「複数LINEチャネル連携」が可能か念のため確認したいです。
```

### Q1-4. 簡易アンケートフォーム＋タグ自動付与＋ステップ配信開始

```
LINE友だち追加直後に送る簡易アンケートフォームを作りたいです。

【フォーム仕様】
- 質問数：3〜4問
  Q1.お名前
  Q2.メールアドレス
  Q3.興味あるサービス（BizOwner / SARUDEMO / 学び家 / まだ決めてない から選択）

【回答完了時に自動でやってほしいこと】
1. Q3の選択に応じて流入タグを自動付与
   - BizOwner選択 → source_BO 付与
   - SARUDEMO選択 → source_SARU 付与
   - 学び家選択 → source_MANA 付与
2. 回答者宛のステップ配信（後で別途作成）を自動開始

【聞きたいこと】
- フォームの作成手順
- 質問項目とタグの紐付け（条件分岐）の設定手順
- 回答完了→ステップ配信開始のトリガー設定手順
- このフォームを2つのLINE（BO+学び家用 / SARUDEMO用）それぞれで使い分ける方法
```

### Q1-5. 会員サイト（タグ条件でアクセス制御）

```
会員サイトを作りたいです。

【サイト仕様】
- ログイン方式：メアド+パスワード（決済完了時に自動発行）
- ページ構成：
  ・全会員共通エリア（マイページ・紹介URL表示・お知らせ）
  ・paid_BOタグ保有者だけ見えるエリア（BizOwner会員コンテンツ）
  ・paid_SARUタグ保有者だけ見えるエリア（SARUDEMO会員コンテンツ）
  ・paid_MANAタグ保有者だけ見えるエリア（学び家会員コンテンツ）
- 「後追い購入ボタン」をタグ条件で出し分けたい：
  ・「学び家を追加する」ボタン → NOT paid_MANA の人だけに表示
  ・「法人作成を申し込む」ボタン → paid_BO AND NOT paid_corp_BO の人だけ
  ・「FC加盟の面談を予約」ボタン → paid_BO AND NOT paid_FC の人だけ

【聞きたいこと】
- 会員サイト本体の作成手順
- ページ/エリアごとに「タグ条件で表示/非表示」を設定する方法
- AND/NOT などの複合条件が指定できるか
- 中身の動画は後でアップロードするので、最初は「準備中」プレースホルダで作りたい
```

### Q1-6. 決済代行（Stripe または Univapay）連携

```
決済代行サービスをUTAGEと連携したいです。

【決済仕様】
- 月額サブスク（BizOwner月11,000円・初月無料・解約自由）
- 一括決済（SARUDEMO 300万円・クレカ可）
- スポット決済（法人作成10万円・FC加盟500万円）
- 決済時にチェックボックスでオプション追加（学び家+月10,000円）

【聞きたいこと】
1. UTAGEで対応している決済代行（Stripe / Univapay 等）の比較・推奨
2. 選んだ決済代行のAPIキー取得手順
3. UTAGE管理画面でAPIキーを登録する手順
4. テスト決済を1回通す手順（テストカード番号など）
5. 特商法表記・プライバシーポリシー・利用規約の登録場所
6. 決済完了をトリガーに「タグ自動付与」「メール送信」「メンバーサイト招待」を実行する設定方法

なお、まだ決済代行は契約していないので、その契約も含めてアドバイスいただきたいです。
```

```
- 決済完了時のアクション（タグ付与・メール送信・メンバー招待）の設定
- 一般公開しないフォーム（個別URLのみで決済）の作り方
- 特商法・利用規約の同意チェックボックスの追加
```
